![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-2b5b84)
![AI](https://img.shields.io/badge/AI-Constraint_Satisfaction-8a2be2)

A Sudoku solver that treats the puzzle as a **constraint satisfaction problem (CSP)**. It comes with a Tkinter visualizer that shows the search as it happens: values are placed in green and flash red when the solver backtracks. You can switch the heuristics on and off to watch how much work each one saves.

## How it works

Sudoku maps directly onto a CSP:

- **Variables:** the 81 cells
- **Domains:** the digits 1–9
- **Constraints:** a cell's 20 *peers* (same row, column and 3×3 box) must all hold different values

The solver is a depth-first **backtracking search** with two optional improvements:

| Technique | What it does | Where |
|---|---|---|
| **Backtracking** | Assign a value to an empty cell, recurse, and undo the assignment if it leads to a dead end | `backtrack()` |
| **MRV (Minimum Remaining Values)** | Always fill the empty cell with the *fewest* legal values next, so failures surface early | `find_MRV()` |
| **Forward checking** | After placing a value, remove it from every peer's domain. If any peer runs out of options, prune immediately | `forward_check()`, `fcbacktrack()` |

## Benchmark

All four modes ran on the same 30 generated **Hard** puzzles, headless and without the GUI's animation delays (averages):

| Mode | Values placed | Backtracks | Time |
|---|---:|---:|---:|
| Backtracking | 180 | 136 | 30.4 ms |
| Backtracking + MRV | 48 | 4 | 8.8 ms |
| Forward checking | 92 | 48 | 2.4 ms |
| **Forward checking + MRV** | **48** | **4** | **2.3 ms** |

MRV removes almost all backtracking: placements drop from 180 to 48, close to the number of empty cells. Forward checking makes each step cheaper because domains are updated incrementally instead of being recomputed from scratch.

## Using the visualizer

```bash
git clone https://github.com/SultanAbdulaziz/Soduko-solver.git
cd Soduko-solver
python gui.py
```

1. Pick a difficulty (**Easy**, **Medium** or **Hard**) and click **Generate**.
2. Toggle **MRV** and **Forward Checking** to choose the search strategy.
3. Click **Solve** and watch the search:

| Color | Meaning |
|---|---|
| Gray | Given clue |
| Green | Value placed by the solver |
| Red flash | Value removed while backtracking |

Puzzles are generated by solving an empty grid and then clearing random cells. Harder levels clear more of them.

Tkinter ships with Python on Windows and macOS. On Debian or Ubuntu, install it with `sudo apt install python3-tk`.
